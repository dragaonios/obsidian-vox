## 🎮 How to Use

### Installation
1. Clone this repo into your Obsidian plugins folder:
   ```bash
   cd /path/to/vault/.obsidian/plugins
   git clone https://github.com/dragaonios/obsidian-vox.git
   ```

2. Install dependencies:
   ```bash
   cd obsidian-vox
   npm install
   ```

3. Build the plugin:
   ```bash
   npm run build
   ```

4. Enable "Ash'Luxael Vox" in Obsidian Settings → Community Plugins

### Opening the Quantum Timeline

**Method 1**: Click the ⭐ star icon in the ribbon (left sidebar)

**Method 2**: Command Palette (Cmd/Ctrl + P) → "Open Quantum Timeline"

**Method 3**: Ribbon menu → Right sidebar → Quantum Timeline tab
