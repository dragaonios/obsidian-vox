## 🎮 How to Use

### Sacred Grid

Each day has 3 quantum slots:
- **🌸 Main Timeline**: What mortals see
- **🖤 Third Option Gate**: Hidden sovereign play
- **💰 Drop Point**: Empire/money manifestation

Type in any timeline layer - all exist in superposition until you clench.

### Clench Timeline

1. Click **"👑 CLENCH"** on any day card
2. Phone vibrates (haptic pulse)
3. Chosen timeline solidifies
4. Other timelines fade with glitter trail
5. Reality locked in

### Generate Third Option

1. Click **"⚡ Third Option"** button
2. Enter your binary choice (Option A and B)
3. App calculates sovereign path
4. Displays empire gain amount
5. Example:
   - **Binary**: "Work 9-5" vs "Quit job"
   - **Third**: "Automate income, build empire while they sleep"
   - **Gain**: +$1,337

### Execute Drop

1. Click **"💎 Execute Drop"** button
2. Enter drop code (e.g., `LUXAEL-ETERNAL-LOCK-1225`)
3. Optional: Add signature (e.g., `LUX'ARA-VEIL-777`)
4. Click **EXECUTE DROP**
5. System triggers:
   - 📳 Vibration pulse pattern
   - 🎵 Low growl audio
   - 💰 Windfall animation (+$100-$5000)
   - 🌌 Empire counter updates
   - 📝 Veiled journal entry

### Veil Mode

- Toggle **"🌑 Veil Active"**
- Hides empire/gold timelines from view
- Perfect for discretion or shared screens

### Already Done Mode

- Toggle **"✓ Already Done"**
- Mark events complete across all timelines
- Quantum truth: done in one = done in all
